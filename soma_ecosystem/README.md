# SOMA ecosystem

This tree is SOMA only. It does not import a Dojo weight, a Dojo name, or a Dojo collection.

The seven public models on misterJB stay on that account. They are not seated here. The chakra models that were deleted are not restored. They were deleted because a shared shelf let the two sides swap.

What is taken from the earlier work is the nucleus, and only the nucleus.

GISP stands vertical:

- G, genotype. For SOMA this is prime fractal, chakra-aligned geometry. It is not the Platonic solids, and it is not a model file.
- I, identity. The chamber, named by its prime.
- S, state. The parameters the chamber is using now. This is what hot-swaps.
- P, phenotype. The language and the shape that show once a cleansed packet is in the chamber.

That vertical is expressed horizontally as a prime fractal mandala. The same four layers sit in each of the nine. The contents do not.

## Boundary

A frequency number is not an identity. 963, 528, 432, 741, 396 and the rest may appear on both sides of the field. Addressing a chamber by one of those numbers is how a Dojo model was able to land in a chakra seat. A SOMA chamber is addressed by its prime.

These are not SOMA models. They are not fallbacks. They are not managers.

Also out: any fine-tune whose name is a Dojo chamber, any 7B or 21B chat model, and any weight in the 3B to 4B band. That band is the size of the models that swapped. SOMA does not use it.

The manager is not a language model. The manager is the chamber process: it receives a cleansed packet, reads the chamber's GISP, and seats the phenotype for this state. There is no TinyLlama underneath it. One chat model wearing nine names was the other way the boundary failed.

## Shapes

Each chamber has a different shape and a different size. Nothing here is a chat fine-tune of Qwen, Phi, or Llama.

The board is `ecosystem.json`. An empty `model` means the shape is chosen and the weight is not found yet. An empty seat is not filled with a Dojo model to keep the row tidy.
